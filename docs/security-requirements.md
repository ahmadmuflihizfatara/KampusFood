### Security Requirements

**SR-1 Injection Prevention**
Ketika login wajib memeriksa dan mencegah input injection berbahaya

**SR-2 Secure Cryptography Implementation**
Terapkan kriptografi yang aman pada setiap transaksi antara mahasiswa dengan kantin ketika
menggunakan aplikasi

**SR-3 General Data Protection**
Melindungi data transaksi klien dengan aman

**SR-4 Log Protection**
Melindungi setiap log yang tercatat pada setiap aktivitas dan transaksi pada aplikasi dari peretasan dan pencurian

**SR-5 Error Handling**
Aplikasi wajib menerapkan penanganan error terutama ketika proses transaksi
